# Legal policies — how to publish these

**Read this file. Do NOT paste this file into Shopify.**

Each `.html` file in this folder contains a policy body and nothing else: no
headings like "1 · Refund policy", no instructions, no notes to the reader.
That is deliberate. On 27 Aug 2026 the live Refund policy at
`/policies/refund-policy` was found to contain an entire handover note —
starting "I couldn't publish these myself: the Shopify connection doesn't have
the write_legal_policies permission" — followed by three prayer-stool policies
and two links pointing at claude.ai. It had been public for some time, on the
page the homepage guarantee links to.

That happened because a document containing both instructions and policy text
was pasted whole into the policy box. Keeping the two apart makes it impossible
to repeat.

## To publish

Shopify admin -> Settings -> Policies. For each file, open the matching box,
select all existing content, delete it, paste the file contents, save.

| File | Shopify box |
|---|---|
| `refund-policy.html` | Refund policy |
| `shipping-policy.html` | Shipping policy |
| `terms-of-service.html` | Terms of service |

Privacy policy: leave alone. The live one is Shopify's own generated template
and is correct. The old Thermawell-branded draft that used to sit here has been
deleted so nobody pastes it over a working policy.

## Before you publish — one thing only you can supply

These are written for **Jointwell, trading at velagoods.co.uk**, with support at
support@velagoods.co.uk. If you trade through a registered limited company, add
the registered name, company number and registered address to the Contact
section of `terms-of-service.html`. UK consumers are entitled to know who they
have contracted with, and "Jointwell" alone does not tell them.

## Keep these in step with the site

The site promises 30-day returns with return postage paid, a two-year warranty,
free UK delivery, and dispatch in 1-3 working days for roughly 9 in 10 orders.
These policies say the same. If you change one, change the other.
